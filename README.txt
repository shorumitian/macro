MY FOOD LOG PWA V2 - IPHONE INSTALL

This package includes your Breakfast, Snacks, and Lunch/Dinner food menu.

A PWA must be hosted on an HTTPS website. Opening index.html directly from the iPhone Files app will not enable the full install/offline behavior.

Upload these five files together without renaming them:
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png

Then on iPhone:
1. Open the hosted site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

The app saves daily logs and targets locally on the iPhone. Use Export CSV for backup.

Data interpretation for entries with omitted fields:
- 2 egg + 1 white: C 0, P 16, F 10, 154 cal
- 2 egg: C 0, P 13, F 10, 142 cal
- Yogurt: C 10, P 15, F 0, 100 cal
- Fruit: C 18, P 0, F 0, 72 cal
- Makhana: C 30, P 4, F 0, 136 cal
- Oil: C 0, P 0, F 4, 36 cal
- Kidney beans: C 35, P 12, F 0, 188 cal
- Papad: C 6, P 2, F 0, 32 cal
